# Robur DS (Vue)

Design System agéntico de Robur, escrito en Vue 3. Es el mismo sistema que
[robur-ds-react](https://github.com/diegosanigle/robur-ds-react): mismos tokens, mismos
contratos y mismos componentes, construidos de forma nativa en Vue.

```bash
npm install
npm run storybook
```

Storybook: https://diegosanigle.github.io/robur-ds-vue/

Estado: proyecto montado, tokens en dos temas, y los dos primeros componentes (`Button` e
`Input`) con sus stories y sus tests de interacción y accesibilidad en `npm test`.

Los tokens (`tokens/`) no se editan aquí: se cambian en `robur-ds-react` y se copian.
